# JMP รายงานรายได้

เว็บแอปแบบ static สำหรับอ่านไฟล์ส่งออกรายงานใบแจ้งหนี้ (`.xlsx`) แล้วสรุปรายได้รายห้อง
ทำงานทั้งหมดในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์ ไม่มีการอัปโหลดข้อมูลไปที่ใด

## ทำอะไรได้บ้าง

- อ่านไฟล์รายงานใบแจ้งหนี้ (ชีต "รายงานใบแจ้งหนี้") ตรวจหาแถวหัวตารางอัตโนมัติ และตรวจสอบว่าผลรวมรายการตรงกับช่อง "รวม"
- จับคู่คอลัมน์รายการจำนวนมาก (ปัจจุบัน 83 คอลัมน์ หลายคอลัมน์ใช้ครั้งเดียว) เข้ากลุ่มรายได้
  เช่น ค่าเช่าห้อง ค่าเช่าเฟอร์นิเจอร์ ส่วนลดประเภทต่างๆ ค่าน้ำ ค่าไฟ และกลุ่ม "ไม่นับ" สำหรับรายการที่ไม่ใช่รายได้
- มีกฎอัตโนมัติ (regex) ช่วยเดากลุ่ม ผู้ใช้ยืนยันหรือเลือกเอง การยืนยันถูกจดจำไว้ในเบราว์เซอร์ (localStorage)
  และส่งออก/นำเข้าเป็นไฟล์ JSON ได้
- หน้าสรุปผล: ตัวกรองปี ช่วงเดือน ห้อง สถานะบิล และชื่อลูกค้า พร้อม 4 มุมมอง
  1. ห้อง × กลุ่ม — ยอดต่อห้องแยกตามกลุ่ม แถวรวม เรียงตามคอลัมน์ได้
  2. Pivot รายเดือน — เหมือน PivotTable ใน Excel: แถว = ห้อง (แยกลูกค้าได้) คอลัมน์ = ม.ค. … ธ.ค. + Grand Total เลือกค่าที่แสดงได้
  3. แนวโน้ม — กราฟแท่งซ้อนรายเดือนตามกลุ่ม พร้อมเส้นรายได้สุทธิ
  4. รายละเอียดบิล — ตารางบิลทุกใบพร้อมยอดแต่ละกลุ่ม คลิกเลขห้องในมุมมองอื่นเพื่อกรองมาที่นี่
- ส่งออกทุกตารางเป็น `.xlsx`

## วิธีใช้

1. เปิด `index.html` (เปิดจากเครื่องโดยตรง หรือผ่าน GitHub Pages ก็ได้ ต้องต่ออินเทอร์เน็ตเพื่อโหลดไลบรารีจาก CDN)
2. ขั้นที่ 1 **โหลดไฟล์** — ลากไฟล์ `.xlsx` มาวาง หรือคลิกเลือกไฟล์ จะเห็นสรุปจำนวนบิล ช่วงวันที่ สถานะ และแถวที่ผลรวมไม่ตรง
   ต้องเลือกไฟล์ใหม่ทุกครั้งที่เปิดหน้า (ไฟล์ไม่ถูกเก็บไว้ในเบราว์เซอร์)
3. ขั้นที่ 2 **จับคู่คอลัมน์** — ตรวจคอลัมน์ที่ "ยังไม่กำหนด" (สีส้ม) และ "เดาให้" (สีเหลือง)
   กด "ยืนยัน" หรือเลือกกลุ่มจากช่องเลือก หรือกด "ยืนยันทั้งหมดที่เดาให้" ครั้งต่อไปคอลัมน์ที่ยืนยันแล้วจะไม่ถามซ้ำ
   คอลัมน์ที่ยังไม่กำหนดจะถูกนับในกลุ่ม "อื่นๆ" และมีคำเตือนในหน้าสรุป
4. ขั้นที่ 3 **สรุปผล** — ปรับตัวกรองด้านบน สลับมุมมองด้วยแท็บ กดปุ่ม "ส่งออก .xlsx" ในแต่ละตาราง
5. **ตั้งค่า** — เพิ่ม/แก้/ลบกลุ่ม แก้กฎอัตโนมัติ (ทดสอบกับชื่อคอลัมน์ในไฟล์ที่โหลดได้) ดูและล้างการยืนยันคอลัมน์
   ส่งออกการตั้งค่าเป็น `jmp-settings.json` เพื่อสำรองหรือย้ายไปเครื่องอื่น นำเข้ากลับได้ และคืนค่าเริ่มต้นได้

ค่าเริ่มต้นของสถานะบิลที่นับ: `ชำระเงินแล้ว` และ `ค้างชำระ` (รวม `ยืนยันชำระเงินโดยพนักงาน` ถ้ามี) ส่วน `แก้ไขบิล` ไม่นับ
เปลี่ยนได้ที่ตัวกรองสถานะในหน้าสรุปผล การติ๊กเลือกมีผลเฉพาะครั้งนี้ ถ้าต้องการให้จำไว้ใช้เป็นค่าเริ่มต้นครั้งต่อไป
กดปุ่ม "จำเป็นค่าเริ่มต้น" ข้างช่องสถานะ (เก็บใน localStorage และอยู่ในไฟล์ `jmp-settings.json`)
กด "คืนค่าเริ่มต้น" ในหน้าตั้งค่าเพื่อกลับไปใช้ค่าเดิม

## ความหมายของตัวเลข

- **รายได้หลัก** = ผลรวมกลุ่มประเภท "รายได้หลัก" (ค่าเช่าห้อง เฟอร์นิเจอร์ ส่วนกลาง แอร์ ทีวี ตู้เย็น)
- **ส่วนลด** = ผลรวมกลุ่มประเภท "ส่วนลด" (ค่าติดลบ)
- **รายได้สุทธิ** = รายได้หลัก + ส่วนลด + อื่นๆ (ไม่รวมน้ำ/ไฟ และไม่รวมกลุ่ม "ไม่นับ")
- **สาธารณูปโภค** = ค่าน้ำ + ค่าไฟ แสดงแยกจากรายได้
- **ค้างชำระ** = ผลรวมช่อง "รวมสุทธิ" ของบิลสถานะค้างชำระในช่วงที่กรอง
- **รวมสุทธิ (บิล)** = ช่อง "รวมสุทธิ" จากไฟล์ (รวมทุกรายการรวมน้ำ/ไฟ)

## นำขึ้น GitHub Pages

1. push โค้ดขึ้น GitHub ที่ branch `main` (ไฟล์ `.xlsx` ถูกกันไว้ใน `.gitignore` จะไม่ถูก commit)
2. ใน repository ไปที่ **Settings → Pages**
3. หัวข้อ **Build and deployment** เลือก Source = **Deploy from a branch**, Branch = **main**, Folder = **/ (root)** แล้วกด Save
4. รอสักครู่ หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ไม่มีขั้นตอน build ไฟล์ทุกอย่างเป็น HTML/CSS/JS ธรรมดา ไลบรารี (SheetJS 0.18.5, Chart.js 4) โหลดจาก cdnjs

## ข้อควรระวังเรื่องข้อมูล

- ไฟล์รายงานใบแจ้งหนี้มีชื่อลูกค้า **ห้าม commit ขึ้น repo** (`*.xlsx` อยู่ใน `.gitignore` แล้ว)
- การอ่านไฟล์เกิดในเบราว์เซอร์เท่านั้น ไม่มีการส่งข้อมูลออก
- การตั้งค่า (กลุ่ม กฎ การยืนยันคอลัมน์ และสถานะเริ่มต้นที่บันทึกไว้) เก็บใน localStorage ของเบราว์เซอร์นั้น ถ้าเปลี่ยนเครื่องให้ส่งออก/นำเข้า JSON

## โครงสร้างไฟล์

```
index.html         หน้าเดียว มี 4 ส่วน: โหลดไฟล์ / จับคู่คอลัมน์ / สรุปผล / ตั้งค่า
css/style.css
js/settings.js     กลุ่มและกฎเริ่มต้น การ normalize ชื่อคอลัมน์ เครื่องมือกฎ บันทึก/นำเข้า/ส่งออก
js/parser.js       อ่าน xlsx → รายการบิล + สถิติคอลัมน์ + ตรวจผลรวม
js/aggregate.js    ฟังก์ชันคำนวณ: ตัวกรอง ห้อง×กลุ่ม pivot รายเดือน อนุกรมสำหรับกราฟ
js/ui.js           การแสดงผลทุกหน้า ตาราง กราฟ ส่งออก
js/app.js          สถานะของแอปและการเชื่อมเหตุการณ์
test/run.mjs       ทดสอบโมดูลหลักกับไฟล์จริง (npm test)
test/ui-smoke.mjs  ตรวจความสอดคล้องของ id ใน HTML/JS และโหลดสคริปต์ทั้งหมดใน node
```

## ทดสอบ

```
npm install
npm test                  # โมดูลหลัก ต้องมี report-01_01_2017-30_09_2026.xlsx ในโฟลเดอร์โปรเจกต์
node test/ui-smoke.mjs    # UI smoke
```
